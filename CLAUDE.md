# Instruções para o Claude Code

## Commits e pull requests
- Não adicionar as linhas `Co-Authored-By` nem `Claude-Session` nas mensagens de commit.
- Não adicionar a linha "Generated with Claude Code" (nem links de sessão) nas descrições de PR ou em comentários.
- Antes do primeiro commit da sessão, configurar o autor:

  ```bash
  git config user.name "Arthur Felipe"
  git config user.email "arthurtroiii513@gmail.com"
  ```
